使用 Koharia 阅读

Koharia 是一款免费、开源的 Komga Android 阅读器。 它将专注的漫画阅读体验与独立的可重排 EPUB 阅读流程结合在同一个应用中，让书库中的不同内容都能以更适合的方式呈现。

Koharia 基于 Mihon 的 Android 阅读器基础开发，将书库浏览、作品详情、离线访问和阅读设置整合在同一应用中。

清晰有序的书库​

Koharia 可将漫画和图书书库分开管理，也可在统一视图中浏览。 封面网格和列表、搜索、筛选、排序、阅读历史以及多服务器快速切换，帮助你快速回到想读的作品。

作品详情页将封面、元数据、简介、标签和章节整合在一起，让发现作品与继续阅读形成连贯的体验。

为漫画而设的阅读器​

  • 支持分页和连续滚动、从左到右或从右到左阅读，以及可选的双页显示。
  • 可使用缩放、旋转、裁边、章节切换和阅读进度控制，让画面更适合内容和设备。
  • Koharia 会优先加载当前页面，并按阅读方向预取相邻页面，带来更顺畅的连续翻页体验。

专用 EPUB 阅读体验​

对于可重排 EPUB 图书，Koharia 提供分页和连续滚动阅读，并可细致调整字体、字号、行距、段落间距、页边距、首行缩进、背景颜色、亮度和翻页方式。

EPUB 阅读器还提供目录、书签、全文搜索、章节切换、阅读百分比和视觉页码。 排版发生变化时，Koharia 会重新计算页数，并在条件匹配时复用已有的分页结果。

阅读进度与离线访问​

阅读位置、历史记录和书签会保存在设备上，并可将受支持的阅读进度同步到 Komga。 手动下载、图书缓存与漫画页面缓存分别管理，网络不稳定时也能保留需要的内容。
