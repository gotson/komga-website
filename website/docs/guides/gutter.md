# Read with Gutter

[Gutter](https://apps.apple.com/us/app/gutter-comic-reader/id6831270255) is a third-party comic reader for iPhone and iPad. It connects directly to Komga through the REST API, keeps a copy of your library on the device so it still browses when the server is out of reach, and syncs read progress both ways.

## Install and connect {#install}

You need iOS or iPadOS 26 or later and a Komga server that your device can reach.

1. Download Gutter from the [App Store](https://apps.apple.com/us/app/gutter-comic-reader/id6831270255).
2. On the **Connect to your comic server** screen, select **Komga**.
3. Enter the **Server address**, such as `https://komga.example.com`. Include the port and any reverse proxy base path if your server uses them.
4. Enter your Komga **Username** and **Password**, or tap **Use an API key** and paste a key from your Komga user settings.
5. Tap **Connect**. Gutter syncs your libraries and opens the Read tab.

To add another server later, go to **Settings** → **Servers**.

## Features {#features}

- Page or vertical scroll mode, left-to-right or right-to-left, fit to screen, width or height.
- Read progress syncs both ways through the Komga API; the library is mirrored on the device.
- Guided zoom steps through a page panel by panel (panels are found on the device) and through two-page spreads half by half.
- Reading queues, search, filters and sorting.
- Free to read, stream and sync. A one-time Gutter Pro purchase adds offline downloads, guided zoom, more than one server and reading stats.
