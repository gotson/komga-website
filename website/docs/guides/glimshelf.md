# Read with Glimshelf

[Glimshelf](https://glimshelf.com) is an independent comic and manga reader for iPhone and iPad that connects directly to your Komga server. It requires iOS or iPadOS 18 or later and Komga 1.20 or later. Glimshelf also runs on iPhone Duo in compatibility mode.

## Adding your Komga server {#add-server}

1. Download Glimshelf from the [App Store](https://apps.apple.com/us/app/glimshelf/id6802456311).
2. Open **Settings** → **Manage Servers**, tap **+**, and choose **Komga**.
3. Enter the base address you use to open Komga in a browser, including the scheme and any path prefix. Use an address reachable from your device, not a link to a book, library, or OPDS feed.
4. Enter a Komga API key or sign in with your Komga username and password.
5. Tap **Save**. Connection Doctor checks the connection before adding the server. If a check fails, it shows which step needs attention.

## Reading and offline use {#reading}

Browse and search your libraries, follow Komga read lists, and stream books or download them before going offline. Glimshelf syncs reading progress with Komga, including progress made offline once your server is reachable again. Your Komga account's library and download permissions still apply.

## Free and Pro {#pricing}

Free includes unlimited server connections, reading, and Komga progress sync. It can keep up to five server books downloaded at once, including books in Trip Packs. Other books can still stream while you're online, and local files don't count toward the limit. Optional Glimshelf Pro removes the download limit. See the [Glimshelf website](https://glimshelf.com) for current plan details.

## Help and feedback {#feedback}

See [Glimshelf's Komga setup guide](https://glimshelf.com/komga) or email [Glimshelf support](mailto:support@glimshelf.com) for help with the app. Include your Glimshelf and Komga versions and the steps needed to reproduce the issue. Don't include passwords or API keys.
