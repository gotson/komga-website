# Read with ManYue

Komga is supported in [ManYue](https://apps.apple.com/app/id6753895889), a native manga and comic reader for iPhone and iPad (iOS/iPadOS 15+).

:::info
Server libraries (Komga and other servers) are part of ManYue's paid Ultra tier.
:::

## Install and configure {#install}

1. Download ManYue from the [App Store](https://apps.apple.com/app/id6753895889).
2. In ManYue, go to **Library → + → Add Komga Server**.
3. Enter your Komga server URL and credentials.

## Features {#features}

- Connects to Komga, as well as Kavita, Suwayomi, LANraragi, OPDS, SMB and WebDAV
- Local CBZ/CBR/CB7/ZIP/RAR/7z/PDF files, readable offline
- Double-page spreads on iPad
- Sync via iCloud or WebDAV
